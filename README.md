# OPTWORKS 그룹웨어 체험판

**[Windows용 EXE 다운로드](https://github.com/dev-saedal/optworks-groupware-downloads/releases/download/demo-2026.10.22/OPTWORKS-Groupware-Demo.exe)**

Windows 10/11 64비트(Intel·AMD)에서 사용할 수 있습니다.

1. 위 링크에서 EXE 파일을 다운로드해 실행합니다.
2. 자동으로 열린 브라우저에서 **예시 계정으로 로그인**을 누릅니다.
3. 직원·팀장·관리자 계정을 전환하며 결재, 업무, 일정 등을 시험해 봅니다.

별도 압축 해제, Node.js 설치, 관리자 권한이 필요하지 않습니다. 실행한 PC에서 독립적으로 동작하고 내용도 해당 PC에 저장됩니다.

예시 계정 체험판이므로 실제 회사 자료나 개인정보는 입력하지 마세요. 파일에 코드 서명이 없어 Windows 또는 브라우저에서 확인 경고가 표시될 수 있습니다.
